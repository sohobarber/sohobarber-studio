# SOHOBARBER Studio

Buat aplikasi web responsif bernama SOHOBARBER untuk manajemen barbershop.

Desain:

Background hitam dan charcoal.

Aksen hijau neon dan pink.

Tampilan minimalis, modern, tegas.

Gunakan teks SOHOBARBER sebagai logo sementara.

Nyaman digunakan melalui HP dan desktop.

Buat halaman awal berupa halaman login dengan:

Email

Password

Tombol Masuk

Tampilan logo SOHOBARBER

Desain profesional.

Jangan buat database baru.
Jangan gunakan Lovable Cloud.
Jangan membuat data contoh sebagai data asli.
Siapkan aplikasi untuk dihubungkan ke proyek Supabase yang sudah ada.

This project was built with [Lovable](https://lovable.dev).
